秋招blog-面经篇

本文最后更新于 2026-02-21T22:42:35+08:00

闲言开篇

博主在3月份开启北京实习之旅，第一段结束之后便无缝衔接了返深实习。7月份，手上的项目小有所成，便开始着手更新简历、刷 LeetCode、刷面经和八股，正式备战秋招。

博主八月中上旬开始秋招投递，应该是同门中出手最早的一个——这里还是建议大家尽早准备，尽早投递，别错过前期的机会。当然，博主也有同门九月中下旬才开始投递，照样斩获了一批高质量的 offer，所以归根结底，还是要看个人的时间线 ～

流程分析

闲言少说，博主接下来就来分享下各个公司投递和面试的情况，希望能对诸君有所帮助 ～

先贴一下博主前期整理的面试表格（后期没有持续更新）：

【腾讯文档】2026秋招面试

回顾一下博主的 bg：C9 本硕，两篇 NLP 相关顶会（1A1B），两段大厂实习，方向均为后训练相关。博主的 code 和八股水平自诩中上，面试中基本没出什么纰漏（有一两场比较遗憾）。

博主的整体策略是：

  1. 先投中厂人才计划的岗位，包括美团北斗、快手 Star、百度 AIDU、OPPO OStar 等等——人才计划通常流程周期长，早投早被捞；被挂了还能直接转正式批，有可能免笔试，建议有能力的同学都先试一波，不亏。
  2. 同步投一些没有明确意向的中大厂，主打一个练手——借这些公司的面试把流程熟悉了、把薄弱点补上了，在后续心仪公司和岗位上的胜算才更大。
  3. 完全体后再集中投心仪的公司和岗位，面试后及时复盘，不断迭代自己的面试经验 ～

面试整体大概几个环节：

  1. 自我介绍
  2. 项目交流（论文&实习）
  3. 八股+业务场景+编程
  4. 反问

各个公司的流程几乎都在这几个模块以内，大家要做的就是把每个模块打磨到位，力求做六边形战士，没有明显短板。

自我介绍

万事开头难，如果能在开场就让面试官对你产生兴趣，这场面试就已经成功了一半——这部分可以说是重中之重。个人认为，自我介绍的核心在于：在 3 分钟内让面试官清楚看到你的实力。这里的”实力”是多维的：实习经历、科研成果、个人品质（自信、条理清晰）、价值观……能在短时间内把亮点集中展示出来，引导面试官顺着你准备好的方向去聊，就能在整场面试中占据一定的主动权。

具体准备上，一份简洁清晰的简历、一个简洁清晰的 PPT，能帮很大的忙。（当然，最核心的还是个人工作的含金量 ～）

项目交流

这部分完全依托个人简历，准备充分的话压力并不大。建议尽可能熟悉自己工作的每个细节，学会给面试官“挖坑”和“递话”，主动往自己熟悉或擅长的方向去引导。当然这部分还是靠平时的积累和临场应变。面试时间通常是一小时，如果面试官对你的工作感兴趣，会花更多时间深聊，后面的八股和场景拷打自然就少了，甚至直接跳过——所以，好好打磨论文和实习项目，真的非常重要。

八股

这部分因面试官而异，八股或场景题可能在项目交流时穿插问答，也可能在交流结束后才开始，还有一上来就直接开拷的。博主的八股来源主要是小红书刷帖和 LLM面试笔记 这个项目（强烈建议 star！），加上一些相对前沿的 paper 内容，都会结合 GPT 进行整理和优化（善用 LLM 辅助真的很重要）。

业务场景部分，通常是面试官团队实际遇到的一些问题，结合自己的经验去作答就好，往往没有标准答案——能和面试官有来有回地交流，个人认为就已经不错了。

编程题同样看面试官的偏好，有喜欢 Hot 100 的，有喜欢出智力题的，也有喜欢 hard 甚至原创题的——能做的就是夯实基础，保持一定的创新思维。

反问

到了反问环节，就是你的回合了。博主一般会围绕以下几个方向展开：

  1. 团队的业务方向和技术栈
  2. 团队的氛围和作息（这部分要结合交流情况和面试官的性格，看合不合适去问）
  3. 面试官对当前场景和方向的个人思考（博主比较喜欢这种学习型的交流）
  4. 委婉地请面试官给一些建议或意见（顺带评估下自己的发挥，当然要看面试官是否接这个话茬）

最后，博主发现面试多了，在面试结束的那一刻，基于自己的发挥和面试官的态度，大致就能猜到结果了。博主想提醒大家的是：机会很多，流程很长，不要计较一时得失。面试顺利固然好，但失败同样是磨刀石——能帮你找到薄弱点，让自己在下一场中更强大、更自信。所以，不要害怕面试，坦然面对失败，下一个，永远更好。
